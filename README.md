# 쪽집게 영어학원 쇼핑몰

고등 영어 **모의고사**와 **중계동 학교별 내신 문제집**(PDF 등 파일)을 직접 올려서 팔고, **학습 문구**도 함께 파는 사이트입니다.

## 실행

```bash
npm install
ADMIN_PASSWORD=원하는비밀번호 BANK_ACCOUNT="국민은행 000-00-0000 (예금주 홍길동)" npm start
```

- 쇼핑몰: http://localhost:3000
- 관리자: http://localhost:3000/admin.html

## 판매 흐름

1. **관리자 → 상품 등록**: 분류(내신 문제집/모의고사/문구), 가격, 학교·학년, 설명, 판매 파일, 표지, 미리보기를 올립니다.
2. 손님이 장바구니에 담고 주문하면(무통장 입금) 주문번호가 나옵니다.
3. **관리자 → 주문 관리**에서 입금을 확인하고 상태를 `입금 확인`으로 바꿉니다.
4. 손님은 **주문조회·다운로드**에 주문번호와 연락처를 넣고 파일을 내려받습니다.

판매 파일은 `storage/files/`에 비공개로 보관되고, 입금이 확인된 주문의 고유 링크로만 받을 수 있습니다.
표지와 미리보기는 공개됩니다. 데이터는 `data/db.json`에 저장되며, 둘 다 git에는 올라가지 않습니다. 백업해 두세요.
